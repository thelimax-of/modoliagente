Política de Privacidade

Última atualização: 23 de outubro de 2026

Esta política explica como o aplicativo Dark Platform usa os dados acessados por meio dos Serviços de API do YouTube. O Dark Platform é uma ferramenta própria e de uso interno do canal Modo Li Agente. Ela não é oferecida ao público: o único usuário é o próprio dono do canal, que a usa para publicar e acompanhar os vídeos do seu canal no YouTube.

Serviços de API do YouTube

O Dark Platform usa os Serviços de API do YouTube. Ao usar o aplicativo, o usuário concorda com os Termos de Serviço do YouTube. Os dados também estão sujeitos à Política de Privacidade do Google.

Quais dados o aplicativo acessa

Com a autorização do dono do canal, o aplicativo acessa apenas a conta do YouTube dele, para:

  • enviar vídeos, thumbnails e legendas para o canal;
  • ler as estatísticas dos vídeos do próprio canal (visualizações, tempo assistido, porcentagem assistida, inscritos ganhos, curtidas e comentários).

O aplicativo não acessa dados de espectadores, não lê mensagens, não acessa outras contas e não coleta dados pessoais de terceiros.

Como os dados são usados

As estatísticas são usadas somente para entender quais vídeos do canal funcionaram melhor e orientar a escolha dos próximos temas. Os dados não são usados para publicidade nem para criar perfis de pessoas.

Armazenamento

Todos os dados ficam guardados apenas no computador do dono do canal: a credencial de acesso (arquivo token.json) e as estatísticas (um banco de dados local). Nada é enviado para servidores próprios ou de terceiros. As estatísticas antigas podem ser apagadas a qualquer momento pelo dono do canal.

Compartilhamento

Os dados não são vendidos, alugados nem compartilhados com terceiros.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento nas configurações de segurança da Conta Google, removendo o aplicativo Dark Platform. Depois disso, o aplicativo deixa de ter acesso ao canal, e os dados locais podem ser apagados excluindo o arquivo token.json e o banco de dados local.
